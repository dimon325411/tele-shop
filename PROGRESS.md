продление, возврат), админ-команды и аудит, удаление аккаунта, сроки хранения, диалог создания поиска,
форматирование уведомлений, наличие всех ключей перевода.

## Что НЕ запускалось (и почему)
В облачной среде этой сессии закрыт доступ к PyPI, а запуск библиотек, собранных из GitHub в обход
PyPI, запретила проверка безопасности. Поэтому **не исполнялись**:
* `app/bot/*` (aiogram) — обработчики, middleware, отправка сообщений;
* `app/storage/sql.py` (SQLAlchemy + psycopg) — сам Python-код репозитория (его SQL проверен отдельно);
* `app/worker/main.py` (ARQ), `app/api/main.py` (FastAPI), `migrations/env.py` (Alembic), `RedisLocker`;
* `tests/integration/*` — написаны, запускаются в Docker.

Чтобы снизить риск, вся логика вынесена из этих слоёв в тестируемые модули (`wizard.py`,
`controller.py`, `presentation.py`, `worker/jobs.py`, `services/*`), а слои оставлены тонкими.

## Решения, принятые самостоятельно
* SQL-схема — явная SQL-миграция (`migrations/sql/0001_initial.sql`), запросы — SQLAlchemy Core `text()`
  в одном модуле; так каждый запрос проверяется на настоящем PostgreSQL. ORM-модели не используются.
* Драйвер БД — psycopg 3 (`postgresql+psycopg://`), один и тот же для приложения и Alembic.
* Первая проверка поиска не рассылает уже существующие объявления, а присылает сводку
  (`NOTIFY_ON_FIRST_RUN=false`).
* Объявления без цены не отправляются, если в поиске задан диапазон цены; прочие отсутствующие поля
  пропускаются по умолчанию (настраивается в поиске).
* Пробный период выдаётся автоматически при первом `/start` (3 дня, 2 поиска, проверка раз в 15 минут).
* Цены тарифов (150/350/700 ⭐ за 30 дней) — заглушки, меняются `/plan_set`.
* Смена тарифа — сразу, с пересчётом остатка в дни нового тарифа.
* Платежи выключены по умолчанию: обычный (боевой) токен не работает в тестовой среде Telegram.
* Демо-режим `python -m app.dev_run` — без Docker/PostgreSQL/Redis, данные в памяти.

## Известные ограничения
* Радиус работает только для объявлений с координатами; геокодирования города нет, поэтому мастер
  радиус не спрашивает.
* Нет английского/русского интерфейса (структура `app/i18n` готова).
* Версии зависимостей заданы диапазонами; после первой установки закрепить `pip freeze`.
