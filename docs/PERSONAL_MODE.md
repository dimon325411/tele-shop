# Личный режим (PERSONAL_MODE)

Решение владельца (2026-10-24): для личного использования включать мониторинг OLX.pl.
Коммерческая версия (подписки, Telegram Stars) **остаётся в коде без изменений** и включается
обратно одной настройкой.

| | `PERSONAL_MODE=false` (коммерческий) | `PERSONAL_MODE=true` (личный) |
|---|---|---|
| Кто может пользоваться | все | только `ADMIN_IDS`; остальные получают «prywatny bot» и не регистрируются |
| OLX.pl | выключен (регламент п. 2.3) | читаются публичные результаты поиска |
| Allegro Lokalnie | выключен | выключен |
| Подписки и оплата | пробный период, Stars | выключены; владелец получает скрытый тариф `personal` |
| Частота проверки OLX | — | не чаще раза в 10 минут на поиск; между запросами к OLX ≥ 10 с |

## Как OLX читается
* Публичный адрес `https://www.olx.pl/api/v1/offers/?query=…&sort_by=created_at:desc` —
  его `robots.txt` OLX явно разрешает роботам (`Allow: /api/v1/offers/`).
* Без входа в аккаунт, без cookies, с честным User-Agent, с тайм-аутами.
* Ответ 403/429 или страница с CAPTCHA → источник ставится на паузу (по умолчанию на час, либо по
  `Retry-After`), запросы не повторяются, ничего не обходится. Видно в `/status` и `/admin_sources`.
* Неизвестная структура ответа → поиск помечается ошибкой «layout», данные не выдумываются.
* Ссылки в уведомлениях — настоящие ссылки на объявления OLX из ответа; объявления, ведущие на
  другие сайты (например, Otodom), пропускаются.

## Риски (честно)
* Регламент OLX п. 2.3 запрещает агрегацию данных для передачи третьим лицам, а также общее
  использование контента без согласия. Личное использование с низкой частотой — серая зона:
  основной практический риск — блокировка запросов с вашего IP, а не судебные претензии.
  Это не юридическая консультация.
* **Не продавайте доступ и не добавляйте других людей в `ADMIN_IDS`** — тогда это уже передача
  третьим лицам.
* Структура ответа OLX написана по публичным данным и не проверялась из среды разработки (OLX был
  недоступен). Проверьте один раз: `python3 scripts/olx_probe.py rower`.

## Включение
В `.env`:
```
PERSONAL_MODE=true
ADMIN_IDS=<ваш Telegram ID>
PAYMENTS_MODE=disabled
```
Затем `python -m app.dev_run` (демо, данные в памяти) или `docker compose up -d --build`.
Бот должен работать с вашего компьютера или сервера; облачные IP площадки часто блокируют сразу.

## Возврат к коммерческой версии
`PERSONAL_MODE=false` — OLX снова отключён, платежи и тарифы работают как раньше.
