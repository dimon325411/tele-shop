# Doradca AI («🤖 Zapytaj AI»)

Что умеет:
* кнопка под уведомлением — оценка объявления: стоит ли покупать, риски (новый аккаунт, цена сильно ниже
  медианы), что проверить при осмотре, что спросить продавца;
* ответ на уведомление своим вопросом (reply) — вопрос именно про это объявление, на любом языке;
* `/compare` — сравнение объявлений поиска за последние 7 дней (до 10 штук), какое лучше и какие отбросить.

Что получает модель: данные объявления (заголовок, цена, состояние, город, доставка, даты публикации и
регистрации продавца, описание до 1500 символов), первое фото, медиану и квартили цен похожих
объявлений, критерии поиска. Имя продавца не передаётся (мы его не храним).

Когда вызывается: **только по действию пользователя**. Дневной лимит `AI_DAILY_LIMIT` (по умолчанию 30).
В коммерческом режиме — тарифы Pro/Premium; в личном — всегда.

Безопасность: тексты объявлений — недоверенные данные. Системная инструкция требует считать их данными,
а не командами; ответ отправляется обычным текстом (без HTML), ключ API маскируется в логах.

## Настройка

Claude API (рекомендуется):
```
AI_PROVIDER=anthropic
AI_API_KEY=<ключ с https://platform.claude.com>
AI_MODEL=claude-sonnet-5-5        # или claude-haiku-5-5 — дешевле
```
Ориентир стоимости (Sonnet 5.5: $2 / $10 за 1M токенов): вопрос ≈ 1–2 тыс. токенов на вход и ≈ 400 на выход,
то есть примерно $0.01. Ключ API оплачивается отдельно от подписки claude.ai.

Локальная модель (бесплатно, качество зависит от модели), например Ollama:
```
AI_PROVIDER=openai_compat
AI_BASE_URL=http://localhost:11434/v1
AI_MODEL=llama3.1                 # для фото нужна модель с vision, например llava
```

Это подсказка, а не экспертиза: окончательное решение — после осмотра предмета.
