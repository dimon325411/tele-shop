# Запуск на Windows-ПК 24/7 (личный режим + локальный ИИ)

Бот работает на вашем ПК, ИИ — локальная модель в Ollama (бесплатно, данные никуда не уходят).
ПК должен быть включён; запросы к OLX идут с домашнего IP, как у обычного пользователя.

## 1. Перенести проект с Mac
1. На Mac остановить бота (в Terminal `Ctrl+C`) — при выходе он сохраняет поиски в `data/dev_state.pickle`.
   **Два бота с одним токеном одновременно работать не могут** (Telegram отдаёт обновления только одному).
2. Скопировать всю папку `telegram-market` на ПК (флешка, облако), **кроме** `.venv`.
   Вместе с папкой переедут `.env` (токен — не публикуйте его), `app/data/olx_categories.json` и сохранённые поиски.

## 2. Установка (один раз)
1. Python 3.12+ с python.org (галочка «Add python.exe to PATH»).
2. Двойной клик `scripts\windows\setup.bat` — создаст `.venv` и поставит зависимости.

## 3. Локальный ИИ (Ollama)
1. Ollama запущена (иконка в трее). Узнать точное имя модели: `ollama list` в PowerShell.
2. В `.env`:
   ```
   AI_PROVIDER=ollama
   AI_MODEL=qwen3:8b        # ТОЧНО как в `ollama list`
   AI_SCREEN_DEALS=true
   ```
   Для RTX 5060 Ti (16 ГБ) подходят qwen3:8b / qwen3:14b / qwen2.5:7b–14b. Модели с `:cloud` в имени —
   не локальные (данные уходят в облако, есть лимиты) — для бота не используйте.
3. Проверка: `.venv\Scripts\python scripts\ai_check.py` — модель должна «odrzucić» тестовое объявление
   с блокировкой iCloud. Скрипт показывает время ответа и подсказки при ошибке.

LM Studio вместо Ollama: вкладка Developer → **Start Server**, модель загружена (Load), в `.env`:
`AI_PROVIDER=openai_compat`, `AI_BASE_URL=http://localhost:1234/v1`, `AI_MODEL=<идентификатор модели из LM Studio>`.

## 4. Запуск
* Вручную: `scripts\windows\run_bot.bat` — окно должно оставаться открытым; при падении или потере сети
  бот перезапускается через 30 с (журнал перезапусков: `logs\bot.log`).
* Автозапуск при входе в Windows: `scripts\windows\install_autostart.bat` (удалить: `schtasks /Delete /TN OlxBot /F`).
* Электропитание → «Переводить в спящий режим: Никогда», иначе мониторинг останавливается.

## 5. Только горячие предложения
В Telegram: `/pack` → «✅ Utwórz pakiet» — 16 поисков (iPhone 13–16 Pro, PS5, Xbox Series X, RTX 3070/3080/4060 Ti/4070,
MacBook Air/Pro M1–M2), б/у, проверка раз в 15 минут. Уведомление приходит, только если:
* цена ≥ 15 % ниже медианы той же модели/памяти/состояния (медиана — минимум из 5 объявлений);
* объявление опубликовано не более 6 часов назад (поднятые старые — нет);
* аккаунт продавца не создан в этом месяце;
* ИИ прочитал описание и не нашёл «битый / iCloud / на запчасти / обмен / предоплата» — иначе отбрасывается;
  «⚠️» — есть сомнения (например, менялся экран), «✅» — признаков нет. Если ИИ не ответил, предложение всё равно приходит.

Первые дни бот только собирает рынок: пока по модели меньше 5 объявлений, медианы нет и «горячих» не будет.
Медиана — по ценам объявлений, а не продаж: реальная прибыль меньше (доставка, торг, время).

Нагрузка на OLX: проверки идут по одной, между запросами ≥ 10 с — примерно 2–3 запроса в минуту на 16 поисков.
При 403/429/CAPTCHA бот ставит OLX на паузу и ничего не обходит.
