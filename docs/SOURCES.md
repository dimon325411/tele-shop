# Источники объявлений: правовая и техническая проверка

Дата проверки: 2026-10-24. Это не юридическая консультация; перед коммерческим запуском
нужна проверка юристом и/или письменное согласие площадок.

## Итог

| Площадка | Реальный сбор | Причина |
|---|---|---|
| OLX.pl | **Отключён** | Регламент прямо запрещает агрегацию данных сервиса для передачи третьим лицам |
| Allegro Lokalnie | **Отключён** | Правила Allegro запрещают scraping материалов без согласия; разрешённый публичный API поиска по Lokalnie не найден |
| Mock (тестовый) | Работает | Тестовые объявления, явно помечены как тестовые, ссылки на `example.invalid` |

Адаптеры `olx` и `allegro_lokalnie` существуют в коде с единым интерфейсом, но возвращают
ошибку `SourceDisabled` с указанием причины. Включить их можно только после появления
разрешённого способа доступа (см. «Что нужно для включения»).

## OLX.pl

**Регламент сервиса OLX.pl, п. 2.3** (документ «Regulamin Serwisu OLX.pl», pomoc.olx.pl):

> «Zabrania się jakiegokolwiek agregowania i przetwarzania danych oraz innych informacji dostępnych w Serwisie…»
> (далее — в целях передачи третьим лицам, на других сайтах или вне интернета)

> «Zabrania się jakiegokolwiek wykorzystywania tych treści bez pisemnej zgody uprawnionych.»

Наш сервис по сути делает именно это: собирает объявления OLX и за плату пересылает
их пользователям бота. Поэтому сбор со страниц OLX без письменного согласия OLX не реализован.

Дополнительно:
- `robots.txt` не закрывает страницы поиска `/oferty/` и `/d/`, но разрешение для
  поисковых роботов ≠ разрешение коммерческой агрегации по регламенту.
- `robots.txt` разрешает `/api/v1/offers/` для роботов, но это недокументированный внутренний
  эндпоинт; его использование для коммерческого сервиса тоже подпадает под п. 2.3.
- **OLX Partner API** (developer.olx.pl) предназначен для управления *собственными*
  объявлениями партнёра (создание/редактирование/доставка). Документация не описывает
  поиск по всему рынку, доступ выдаётся после регистрации приложения.

## Allegro Lokalnie

- **Правила REST API Allegro** (developer.allegro.pl/rules), п. 4.1(e): запрещено использовать
  материалы Allegro, включая данные, без согласия Allegro, «w tym do dokonywania ekstrakcji
  (ang. scraping) tych materiałów». П. 4.1(c): запрещено показывать предложения Allegro
  в конкурирующих сервисах.
- Политика конфиденциальности Allegro (Załącznik nr 5) перечисляет Allegro Lokalnie как одну
  из «Платформ» Allegro, т.е. это одна группа сервисов.
- Регламент Allegro, ст. 2.12(d): Allegro вправе применять механизмы блокировки ботов.
- `robots.txt` allegrolokalnie.pl закрывает для всех только путь выставления объявлений,
  но, как и у OLX, robots.txt не даёт права на коммерческое использование данных.
- REST API Allegro: документация не подтверждает, что поиск по объявлениям Allegro Lokalnie
  доступен через API; регламент самого Allegro Lokalnie напрямую получить не удалось
  (страница вернула ошибку) — это открытый вопрос.

## Что нужно для включения реальных источников

Любой из вариантов:
1. **Письменное согласие / партнёрство** с OLX (OLX Group) и/или Allegro на коммерческое
   использование данных поиска. Контакты: developer.olx.pl, developer.allegro.pl.
2. **Официальный API**, который явно разрешает поиск по публичным объявлениям
   (на момент проверки не найден).
3. **Юридическое заключение**, что конкретная модель (например, пользователь сам
   пересылает боту свои уведомления «obserwowane wyszukiwania» из OLX) не нарушает регламент.

Технически адаптер HTTP+HTML можно добавить в `app/sources/olx.py` /
`app/sources/allegro_lokalnie.py` поверх уже готового «вежливого» клиента
`app/sources/http.py` (ограничение частоты, таймауты, экспоненциальная задержка,
остановка при 403/429/CAPTCHA). Обход CAPTCHA, авторизации и антибот-защиты
не допускается в любом случае.

## Альтернатива, которая уже существует

OLX и Allegro сами предлагают уведомления о новых объявлениях по сохранённым поискам
(«Obserwowane wyszukiwania» в OLX, уведомления в приложении Allegro). Для личного
использования это законный бесплатный способ.

## Платежи

- **Telegram Stars** (core.telegram.org/bots/payments-stars): цифровые товары и услуги в ботах
  продаются только за Stars (`XTR`), `provider_token` пустой, доступ выдаётся только после
  `successful_payment`, нужно хранить `telegram_payment_charge_id`, возвраты — `refundStarPayment`,
  бот обязан отвечать на `/paysupport` и показывать условия (`/terms`) с согласием перед покупкой.
- **Криптовалюта**: та же страница прямо указывает, что для цифровых товаров сторонние
  платёжные провайдеры и криптовалюта не допускаются, в том числе через собственный сайт.
  Поэтому криптооплата реализована только как интерфейс + mock и **заблокирована**
  (`CRYPTO_ENABLED=false`). Подробнее в `docs/PAYMENTS.md`.
