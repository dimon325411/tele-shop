## Следующие шаги (по порядку)
1. Запустить `docker compose --profile tests run --rm tests` (или демо `python -m app.dev_run`) и исправить
   то, что всплывёт в слоях, которые нельзя было запустить в этой сессии (aiogram, SQLAlchemy, ARQ, FastAPI).
2. Живая проверка бота в Telegram: `/start` → создание поиска → уведомление с тестовой ссылкой.
3. Тестовый платёж Stars в тестовой среде Telegram (`PAYMENTS_MODE=test`, отдельный тестовый бот).
4. Закрепить точные версии зависимостей (`pip freeze > requirements.lock`) после первой успешной установки.
5. Решение владельца по источникам: запрос согласия у OLX/Allegro или юридическая оценка альтернатив.
6. (Позже) семантическое сопоставление (эмбеддинги/LLM) как платная функция — только для объявлений,
   прошедших дешёвый фильтр.
